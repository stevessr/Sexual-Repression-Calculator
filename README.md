# 性压抑指数计算器 (Sexual Repression Index Calculator)

> 面向性健康教育和自我反思的本地测评工具，不提供医学诊断。

## 项目概述

性压抑指数计算器以性兴奋/性抑制研究和 WHO、CDC 等性健康框架为设计参考，
帮助用户观察性相关困扰、回避、同意、边界和支持环境。题库中的中文改写尚未完成独立信效度验证，
任何结果都不能替代医疗、心理健康或性治疗专业人员的评估。

### ✨ 核心特性

- 🔬 **循证设计参考**: 使用双控制模型等研究构念，并明确区分研究参考、当前医疗指南和产品自评题目
- ⚡ **双版本支持**: 快测版（约 43-52 题，8-15 分钟）+ 完整版（约 68-136 题，25-40 分钟）
- 📊 **探索性分析**: 四维度 SRI 指数（0-100）+ 近四周困扰与保护性环境摘要；不设置临床诊断切点
- 🔒 **隐私保护**: 100% 本地数据处理，无服务器传输
- 📱 **现代化 UI**: 响应式设计，支持所有设备
- 💾 **数据管理**: 历史记录、数据导出、自动保存
- 🔗 **社交分享**: 多平台分享、智能文案、二维码生成

   - 构建命令：`npm run cf:deploy`
   - 输出目录：`dist`

### 注意事项

- 此应用是纯静态的 React 应用，所有数据处理都在客户端进行

## 📋 功能说明

### 评估版本

#### 🏃‍♂️ 快测版 (推荐)
- **时长**: 8-15 分钟
- **题目**: 约 43-52 题（按人口学信息自适应）
- **内容**：SIS/SES-SF 研究构念题目（14）+ Mosher 性内疚（10）+ KISS-9 性羞耻（9）+ SOS 简版（5）+ 性健康与困扰自评（10）
- **适用**: 初次使用、快速了解；补充自评不计入 SRI 合成

#### 🎯 完整版
- **时长**: 25-40 分钟
- **题目**: 约 68-136 题（按人口学信息自适应）
- **内容**：适应版/完整版研究构念题目 + 性健康与困扰自评（10）
- **适用**: 深入自我反思；不用于临床诊断或重要决策

### 核心算法

#### SRI 指数计算（探索性）
```
SRI = 四个研究维度的标准化分数 → 0-100 显示值
四维度: SOS反向 + 性内疚 + 性羞耻 + SIS相对SES优势
```

SRI 的参考均值不是本地代表性常模，0-100 等级仅用于观察回答模式；
近四周困扰、功能影响、同意/边界和支持环境会单独摘要，不参与 SRI 合成。

#### 等级划分
- 很低 (0-20): 较少压抑
- 偏低 (20-40): 轻度压抑
- 中等 (40-60): 中度压抑
- 偏高 (60-80): 较高压抑
- 很高 (80-100): 高度压抑

## 📊 科学依据

### 研究构念与现行参考

以下材料用于题目设计和结果边界说明，不表示本项目采用了任何原量表的完整授权、中文验证或临床常模：

1. [WHO Sexual health](https://www.who.int/health-topics/sexual-health)：以福祉、尊重、同意、无胁迫和免受歧视/暴力为框架。
2. [WHO ICD-11 浏览器](https://icd.who.int/browse/2025-01/mms/en)：分类与临床沟通工具，不能替代个体化病史和专业判断。
3. [CDC Guide to Taking a Sexual History (2024)](https://www.cdc.gov/sti/hcp/clinical-guidance/taking-a-sexual-history.html)：强调个体化、非评判性和以患者为中心的性史沟通。
4. [CDC STI Treatment Guidelines (2021)](https://www.cdc.gov/std/treatment-guidelines/default.htm)：用于性传播感染预防、筛查和治疗的临床参考，不是本测评的诊断依据。
5. [APA DSM-5-TR](https://www.psychiatry.org/psychiatrists/practice/dsm)：诊断分类资源；临床判断需要持续性、个人困扰/功能影响及鉴别评估。
6. [Bancroft & Janssen (2000)](https://doi.org/10.1016/S0149-7634(00)00024-5)：性反应双控制模型的理论研究。
7. [Janssen et al. (2002), SIS/SES I](https://doi.org/10.1080/00224490209552130) 与 [SIS/SES II](https://doi.org/10.1080/00224490209552131)：性兴奋/抑制研究量表的原始论文。

本项目的中文题目是教育性改写，不声称具有上述研究的信效度；页面中的 SRI 仅是产品定义的探索性显示值。
